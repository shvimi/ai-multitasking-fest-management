# ai-multitasking-fest-management# 🎉 AI Multitasking Fest Management System

## Overview
The AI Multitasking Fest Management System is a Python-based application designed to manage college or organizational events efficiently.  
It uses AI-based logic to handle multitasking activities such as event scheduling, task prioritization, and participant management.

##  Key Features
- Event creation and management
- Participant registration and tracking
- Task assignment for volunteers and teams
- AI-based task prioritization
- Schedule management
- Centralized fest dashboard

##  Technologies Used
- Python
- Flask
- SQL (MySQL / SQLite)
- AI Logic (Rule-based / Basic ML)
- HTML, CSS (Basic)

##  System Modules
- Event Management Module
- Participant Management Module
- Task & Schedule Management
- AI Automation Module
- Database Handling

## Use Case
This system helps colleges and organizations manage fests and events smoothly by reducing manual work and improving coordination using AI-based automation.

## How to Run the Project
1. Clone the repository
2. Install required Python libraries
3. Configure the database
4. Run the main Python file
5. Open the application in the browser
